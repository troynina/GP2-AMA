# Проект
Анализ видеоконтента о карьере в ИТ-компаниях и его влияние на привлечение кандидатов

# Описание проекта
Анализ влияния Youtube видео контента на привлекательность ИТ-компаний для соискателей. Проект объединяет данные о видео с Youtube API, информацию о компаниях с портала DreamJob.ru, данные о топ-100 бигтех компаний России из исследования SmartRanking, а также статистику запросов по этому топу в Яндекс Вордстате.

# Бизнес-задача
Сейчас видеоконтент - один из наиболее эффективных инструментов привлечения талантов. Ит-компании часто используют ютуб чтобы демонсрировать корпоративную культуру, рассказывать о возможностях карьерного роста, чтобы привлекать моодых специалистов и стажеров, а также ютуб нужен чтобы повысить узнаваемость бренда работодателя, но остается открытым вопрос - а насколько эффективен видеоконтент для привлечения кандидатов и как он коррелирует с репутацией компании среди соискателей 
**Основной вопрос:** Стоит ли ИТ-компании инвестировать в youtube видео контент для привлечения кандидатов? Если да, то какие тематики и форматы наиболее эффективны

**Подзадачи:**
1. Определить эффективность различных типов видео контента (шортсы vs полные видео)
2. Выявить наиболее привлекательные категории видео
3. Оценить влияние видео контента на рейтинг компании среди соискателей

# Бизнес-ценность решения
Для новых ит-компаний - помогает понять, стоит ли использовать ютуб как канал hr-бренда, какие видео быстрее повышают узнаваемость

Для существующих компаний - позволяет точнее инвестировать в видео контент, выбирать наиболее эффективные форматы и темы, повышать привлекательность работодателя

Для соискателей - дает более прозрачное представление о компании через видео контент, помогает лучше оценить культуру, команду и улсовия работы, а значит - принимать более осознанное карьерное решение

# Метрики успеха
1) В медиа сфере: уровень интересности был рассчитан на основе нескольких параметров и итоговая формула вышла следующей:
 likes * ((views * min(views / subscribers, 5)) / days_from_publication)

Где:

- Likes - количество лайков
- Views - количество просмотров
- Subscribers - количество подписчиков на канале
- days_from_publication - количество дней со дня публикации видео

Также как доп прокси метрики были взяты следующие метрики:

- Engagement = likes/views - посмотрел - оценил - насколько просмотренный контент нравится пользователям и насколько они реально его смотрят и оценивают, а не пролистывают или сразу закрывают
- Likes per subscribers = likes/subscribers - отражает активность аудитории - по сути метрика стабильности, что люди готовы смотреть регулярно
- Views per subscribers - вторая метрика стабильности, что говорит об интересности видео для кандидатов

2) В сфере компаний:

- Средняя оценка среди кандидатов
- Процент рекомендаций кандидатов
- Количество работников в компании
- Количество отзывов кандидатов

Также наша команда предлагает комбинированную метрику успешностии компании:
интересность_для_кандидата =
(0.6 * rec_share/100 + 0.4 * review/5)
* (1 + 0.2 * ln(1 + review_cnts))
* (1 + 0.1 * ln(1 + mp_cnt))
* (1 + 0.05 * ln(1 + years))

Здесь учитывает отдельно комбинация метрик рекомендации и средней оценки (в сумме должно получиться значение в диапазоне от 0 до 1
* коэффициент для нормированного количества оценок
* коэффициент для нормированного количества работников в компании
* коэффициент для нормированного количества лет со дня открытия компании - то есть уровень зрелости

3) С точки зрения вордстата:
- Количество упоминаний в запросах о карьере и трудоустройстве

# Источники данных
1. Youtube API - ч/з API (ключ обязателен). Видео контент о работе в ит-компаниях
2. DreamJob.ru - ч/з scrapping (request+BeautifulSoup+selenium). Инфо о компаниях и их оценка по отзывам
3. SmartRanking.ru - ч/з scrapping (request+BeautifulSoup). (Рейтинги топ-100 bigtech компаний России). Оценивались масштаб компании и контекст бизнеса: выручка, рост, позиция на рынке, число занимаемых рынков.
4. Wordstat API - ч/з API (ключ обязателен). Использовался в качестве дополнения со стороны заинтересованности кандидатов на трудоустройство в данной компании.

Данные мерджились по названию компании, однако перед этим была проведена обработка названий с помощью библиотеки re, чтобы привести названия к одному регистру и одному виду. В итоге при объединении таблиц контента и данных о компаниях с сайта dreamjob вышло 26425 записи

В рамках парсинга данных с Youtube APU были взяты данные о компаниях из топа бигтех компаний и по каждой компании доставал по 20 видео для каждого из следующих запросов:
• Компания + работа IT
• Компания + стажировка IT',
• Компания + ' карьера IT

Сначала были собраны данные с [сайта топа бигтех компаний на 2024 год](https://smartranking.ru/ru/ranking/big-tech/#:~:text=Table_title:%20%D0%A0%D0%B5%D0%B9%D1%82%D0%B8%D0%BD%D0%B3%20%D0%BA%D1%80%D1%83%D0%BF%D0%BD%D0%B5%D0%B9%D1%88%D0%B8%D1%85%20%D1%82%D0%B5%D1%85%D0%BD%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85%20%D0%BA%D0%BE%D0%BC%D0%BF%D0%B0%D0%BD%D0%B8%D0%B9%20BigTech%20100,%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D1%8B%20%D0%BE%D1%82%20Ozon%20%D0%91%D0%B0%D0%BD%D0%BA%2C%20Ozon%20Travel.%20%7C) 
Далее помощью цикла совершался проход по всем компаниям из данного списка начиная с лучшей компани (Яндекса) и по каждой компании формировался запрос на самые популярнрые видео по запросу Компания + ключевое слово (ключевые слова описаны выше).
Сбор совершался до тех пор, пока не закончится лимит по данному ключу. В итоге удалось собрать 2725 видео по топ 30 компаний для дальнешего анализа.

# Признаки видео контента
1. video_url - string, ссылка на видео ютуб
2. title_video - string, название видео
3. description - string, описание видео
4. video_category - string, категория видео
5. video_type - string, тип видео
6. duration - string, продолжительность
7. published_at - datetime, дата публикации видео
8. view_count - int, кол-во просмотров
9. like_count - int, кол-во лайков
10. subscriber_count - int, кол-во подписчиков канала
11. days_from_publication - int, дней прошло со дня публикации
12. interest_score - float, целевая переменная (интересность видео рассчитана как МАТВЕЙ РАСПИШИ)
13. tags - list, теги видео
14. channel_title - string, название канала-автора

# Признаки компании
1. title_company - string, название компании
2. review - float, средняя оценка компании по отзывам (1-5)
3. rec_share - string, доля рекомендаций компании, %
4. review_cnts - int, кол-во отзывов на dreamjob
5. review_name - string, текстовое описание оценки
6. emp_cnt - string, кол-во сотрудников по категориям (АНЯ РАСПИШИ, в eda проверить)
7. city - string, город (головной офис)
8. year_founded - int, год основания компании
9. industry - string, отрасль деятельности
10. site - string, сайт компании
11. descr - string, описание компании с dreamjob

# Признаки bigtech рейтинга
1. rating - int, место в рейтинг топ-100 компаний России
2. market - string, рынки на к-х работает компания
3. revenue - float, выручка за 2024 год (млн руб)
4. growth - string, прирост выручки 2024/2022, %
5. market_num - кол-во рынков

# Выводы после EDA
Количество просмотров видео о компании на ютубе не имеет влияния на её рейтинг как работодателя, но корреляция относительно количества лайков и совокупного показателя заинтересованности присутствует. Из чего делаем вывод, что продвижение на ютуб актуально для компаний, желающих иметь хорошую репутацию на рынке труда. При этом максимальная лояльность у маленьких ютуб каналов, поэтому при продвижении стоит сделать акцент на них
